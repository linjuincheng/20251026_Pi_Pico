# Streamlit MQTT 監控應用程式 - 產品需求文件 (PRD)

## 專案概述

建立一個基於 Streamlit 的 Web 應用程式，作為 MQTT 訂閱者，即時監控並顯示物聯網設備的狀態數據。

## 專案目的

- **角色定位**：作為 MQTT 訂閱者（Subscriber）
- **主要功能**：即時接收、顯示和儲存 MQTT 訊息
- **應用場景**：監控客廳環境數據（溫度、濕度）及電燈開關狀態

## 介面需求

### 顯示內容

1. **電燈狀態顯示**
   - 顯示電燈的開/關狀態
   - 使用視覺化元件（如開關圖示或狀態指示燈）呈現

2. **環境數據顯示**
   - **客廳溫度**：即時顯示當前溫度數值
   - **客廳濕度**：即時顯示當前濕度數值

3. **數據視覺化**
   - 溫度和濕度使用圖表（Chart）表示
   - **X 軸**：日期和時間
   - **Y 軸**：溫度值（°C）或濕度值（%）
   - 支援歷史數據趨勢顯示

## 功能需求

### 核心功能

1. **MQTT 訂閱功能**
   - 連接到 MQTT Broker
   - 訂閱指定主題（Topic）
   - 即時接收並處理 MQTT 訊息

2. **數據顯示功能**
   - 即時更新顯示接收到的數據
   - 支援多種顯示格式（數值、圖表、狀態指示）

3. **數據儲存功能**
   - 將訂閱收到的資料自動儲存為 Excel 檔案
   - 包含時間戳記、溫度、濕度、電燈狀態等欄位
   - 支援歷史數據累積儲存

### 技術規格

- **前端框架**：Streamlit
- **通訊協定**：MQTT（使用 paho-mqtt 套件）
- **數據格式**：JSON（預期從 MQTT 接收的訊息格式）
- **儲存格式**：Excel（.xlsx）

## 預期主題（Topic）結構

- `客廳/溫度` - 溫度數據
- `客廳/濕度` - 濕度數據
- `客廳/電燈` - 電燈開關狀態

## 未來擴充（可選）

- 數據過濾和搜尋功能
- 數據匯出為其他格式（CSV、JSON）
- 告警功能（溫度/濕度超出範圍時通知）
- 多房間監控支援
